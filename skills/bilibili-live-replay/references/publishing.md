# 上传、草稿与可见范围发布

以下是本地案例在 2026-10-10 观察到的 B 站网页行为，不保证控件名称和 URL 永久不变。操作当前浏览器 UI，先读取工具文档和新鲜页面状态；不复用过期 element id、不用隐藏接口绕过 UI、不读取 Cookie。账号登录或平台验证需要用户处理时，保留检查点并清楚交接。

## 上传前准备

- 从检查点核对目标日期、房间、最终文件、媒体时长/大小及现有草稿 ID / BVID。若正在上传，检查那个会话；不要因草稿箱暂时看不到而重复上传。
- 备齐：最终视频、封面、标题、内容来源、分区、标签、完整简介/歌曲轴、授权事实和期望可见范围。转载标记和来源按实际内容填写，不把旧案例的“作者允许”自动套到新内容。
- 封面复用用户认可的素材；检查 4:3 与 16:9 裁切，不把旧参考稿件当投稿目标。用户没要求重做时不要另造封面。
- 稿件形态先明确：一场一个文件、多个分 P 或多条独立视频。原片与合并版内容相同，不重复上传。

## 文件选择与长上传

1. 使用现有浏览器和目标标签页；先列出标签页验证当前 URL / 标题。进入创作中心的视频上传页。案例看到 `/platform/upload/video/frame`，实际 URL 从当前界面获得。
2. 读取 browser 工具 file-uploads 文档。若支持文件选择器，用可见“上传视频”控件配合 `waitForEvent('filechooser')`，再 `setFiles([绝对路径])`。可访问性树的“Choose Files”未必能被 DOM role 定位，按实际 DOM 调整。
3. 浏览器扩展报“Allow access to file URLs”时，先尝试工具支持的原生文件选择器；不要擅自放宽扩展权限。电脑锁屏阻止原生操作时记录需要用户解锁，不能说文件已上传。
4. macOS 原生选择器：确认正确 Chrome 标签页后打开选择器；Cmd+Shift+G 后**重新读取状态确认路径框出现**，再填写绝对路径、回车，看到正确文件名后点打开。不要把这些步骤盲目批量发送。
5. 等待文件条目确实出现。定期读取上传进度和错误，不反复启动上传。字节进度到 100% 后还可能处于服务端合并阶段；直到显示“上传完成”才保存草稿/投稿。

## 元数据核对

- 设置实际标题、转载/自制类型、来源、分区及标签。平台分区会变，不假定旧“音乐/翻唱”层级仍存在。
- 删除不适用的自动标签。输入一枚标签、回车后等待标签 chip 真正生成，再输入下一枚；快速批量输入曾只保留第一枚。
- 先完整准备简介，再一次填入正确的可编辑区。当前 DOM 中可能有隐藏文本框，必须先确认可见富文本编辑器，不能凭占位符猜测。避免“先清空然后卡住”损失原文；编辑旧稿前保存旧值。
- 读取富文本内容验证每个非空行及顺序。Quill 的 innerText 可能多空行，直接字符串不等不代表丢内容；先按行比较，再检查格式。平台可能自动添加来源链接，核实而非盲目重复粘贴。
- 等封面处理完成，检查封面、标题、标签、简介、文件数量与文件条目的“上传完成”。

## 终点 A：草稿

用户只要求推进到发布前时，点击“存草稿”，不点“立即投稿”。如果点击后仍在上传页，先判断上传/封面是否未完成，不反复点击。

成功标准：页面确认保存、草稿列表出现正确条目，再重新打开该草稿确认上传完成、视频文件和全部元数据。记录草稿 ID、编辑链接和证据截图。案例草稿列表为 `/platform/upload-manager/article?group=draft`，编辑 URL 含 `type=draft&draftId=...`，只使用实际观察到的 ID。

## 终点 B：仅自己可见投稿

用户已授权仅自己可见发布：在“更多设置 → 可见范围”选择“仅自己可见”。先确认所选状态并保存截图，再点击“立即投稿”。不要因为默认值或用户用了“发布”二字就选公开。

提交后检查“稿件投递成功”，再到稿件管理核对**同一标题/BVID** 的“仅自己可见”标记以及审核/转码进度。仅看到提交成功时，报告“已提交，审核/转码中”；不要说已审核通过。记录 BVID / 链接，草稿可能已被消耗，因此后续按 BVID 编辑。

## 终点 C：公开或私密转公开

用户明确要求公开后，直接编辑现有稿件，不重新上传。通过当前稿件的编辑入口，确认 BVID 和标题，设置“公开可见”，提交前确认选中状态，提交后回管理页确认私密标记消失及状态变化。

打开对应视频页确认页面身份、可见性提示和播放状态。若仅管理页设置已保存而视频仍审核/转码，说明公开设置已提交和平台当前状态。只有实际验证了访客/未登录访问才说“已验证对访客可播放”；登录账号能看见自己稿件并不足以证明公开播放完成。

案例编辑 URL 含 `type=edit&bvid=...`，进度页含 `archive-process?bvid=...`。不要根据模板猜出目标 BVID，不动其他视频。审核失败、风控或权限提示先记录具体原因，不能连续重复提交。
